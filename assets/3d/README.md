# 3D-модели для сайта Free Fly

Секция **«Загляни внутрь полёта»** (`#tour`) уже встроена в сайт и работает
через [`<model-viewer>`](https://modelviewer.dev). Пока `.glb` нет — секция
показывает фото. Как только файл появится по нужному пути, 3D включается
**сам** (JS проверяет наличие файла и подставляет его), появляется бейдж
«3D · 360°» и подсказка «Перетащите, чтобы вращать».

## Что нужно смоделить

### 1. `pilot.glb` — пилот в потоке (главный)
Просто положи файл сюда: **`assets/3d/pilot.glb`** — больше ничего менять не надо.

| Параметр | Требование |
|---|---|
| Формат | `.glb` (glTF 2.0 binary), один файл, текстуры внутри |
| Поза | «box» / belly-to-earth: лежит лицом вниз, прогиб в пояснице, руки и ноги разведены в потоке |
| Экипировка | комбинезон Free Fly (сине-белый), фулл-фейс шлем с визором |
| Ориентация | Y — вверх, лицо смотрит в **+Z**; модель по центру начала координат (0,0,0) |
| Масштаб | реальный (≈1.7 м); model-viewer сам подгонит кадр |
| Полигоны | ≤ ~150k треугольников |
| Текстуры | PBR metallic-roughness, ≤ 2K, сжатие Draco / meshopt приветствуется |
| Вес файла | желательно ≤ 8–10 МБ |
| Анимация | опционально: лёгкая «дышащая»/парящая петля. Если добавишь — включу `autoplay` |

AR (кнопка «смотреть у себя») заработает автоматически на телефонах.

### 2. `helmet.glb` — шлем (опционально, для шага «Экипировка»)
Крутящийся шлем с визором. Те же требования по формату/весу. Скажи, если
сделаешь — добавлю мини-вьювер в блок «Как проходит полёт».

## Быстрая проверка

```bash
cd /home/user/sitesdemos && python3 -m http.server 8099
# открой http://localhost:8099/#tour — модель должна появиться и вращаться
```

Если захочешь другой стартовый ракурс — правится атрибут `camera-orbit`
у `<model-viewer id="pilotModel">` в `index.html`.

# Админка Funscool — как включить и пользоваться

Персонал сможет менять контент сайта сам, через форму в браузере, **без GitHub и без кода**.
Вход — по email. Каждое изменение автоматически сохраняется в репозиторий (с историей — всегда
можно откатить), и сайт пересобирается сам за ~1 минуту.

Стек: **Netlify** (хостинг + вход по email) + **Decap CMS** (панель редактирования).

---

## Что уже сделано в коде

- `funscool/content/teachers.json` — данные педагогов (фото, имя, теги, био на RU/SR/EN).
- Секция «Наши педагоги» теперь собирается из этого файла (дизайн не изменился).
- `funscool/admin/` — панель редактирования (открывается по адресу `/admin/`).
- `netlify.toml` — говорит Netlify публиковать папку `funscool/`.

Пока не подключён Netlify — панель откроется, но войти нельзя. Ниже — как включить (5–10 минут, один раз).

---

## Шаг 1. Подключить сайт к Netlify (один раз)

1. Зайти на **app.netlify.com** → войти через GitHub.
2. **Add new site → Import an existing project → GitHub** → выбрать репозиторий `sitesdemos`.
3. Настройки деплоя:
   - **Branch to deploy:** `claude/funscool`
   - **Build command:** оставить пустым
   - **Publish directory:** `funscool`
4. **Deploy** → через минуту сайт будет доступен по адресу вида `https://<имя>.netlify.app`
   (там же можно потом привязать свой домен).

> Бонус: на домене Netlify пропадает окно-предупреждение «One more step», которое показывает raw.githack.

## Шаг 2. Включить вход по email (Netlify Identity)

1. В настройках сайта на Netlify: **Identity → Enable Identity**.
2. **Registration preferences → Invite only** (чтобы регистрироваться могли только приглашённые).
3. **Services → Git Gateway → Enable Git Gateway** (это даёт панели право сохранять правки в репозиторий).

## Шаг 3. Пригласить редакторов

1. **Identity → Invite users** → ввести email сотрудников.
2. Им придёт письмо со ссылкой — они задают пароль и всё.

## Шаг 4. Как редактировать (это уже для персонала)

1. Открыть `https://<имя>.netlify.app/admin/`
2. Войти по email/паролю.
3. **Воспитатели → Список воспитателей** → менять фото/имя/теги/био, добавлять и удалять карточки,
   перетаскивать порядок.
4. Нажать **Publish**. Через ~1 минуту изменения уже на сайте.

---

## Важное про ветку

Сейчас production-ветка — `claude/funscool` (и в Netlify на шаге 1, и в `funscool/admin/config.yml`).
Если позже переедете на `main` — поменяйте её в обоих местах, чтобы совпадали.

## Что дальше (следующие блоки под редактирование)

Тем же способом можно вынести в админку: расписание дня, тексты секций, галерею,
контакты (телефон/адрес/соцсети) и выбор шрифтов/цветов из готового набора.
Педагоги — первый рабочий блок-образец; остальные добавляются по тому же шаблону.

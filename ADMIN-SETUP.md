# Funscool — админка (на GitHub Pages, без Netlify)

Панель редактирования сайта живёт прямо в репозитории (`funscool/admin/`) и работает
на **GitHub Pages** — без Netlify, Cloudflare и любых других сервисов. Редактор входит
по **персональному токену GitHub**, меняет тексты/фото простыми формами и жмёт
«Сохранить». Правка коммитится в репозиторий (с историей — всегда можно откатить), и
сайт автоматически пересобирается за ~1 минуту.

**Адрес панели:** `https://treasureclyde-sketch.github.io/sitesdemos/admin/`
*(после подключения своего домена — `https://твой-домен/admin/`).*

---

## Часть 1. Включить GitHub Pages (делает владелец, один раз)

Это может сделать только владелец репозитория, и только вручную в настройках —
GitHub-бот не имеет на это прав.

1. Открой репозиторий на GitHub → **Settings** → в левом меню **Pages**.
2. Раздел **Build and deployment** → **Source** → выбери **GitHub Actions**.
3. Всё. При следующем пуше в ветку `claude/funscool` workflow `pages.yml`
   опубликует сайт. Статус деплоя виден во вкладке **Actions**.

> Публикуется папка `funscool/` как корень сайта (см. `.github/workflows/pages.yml`),
> поэтому сайт открывается по `…/sitesdemos/`, а панель — по `…/sitesdemos/admin/`.

---

## Часть 2. Создать токен доступа (делает тот, кто редактирует, один раз)

1. Открой **https://github.com/settings/personal-access-tokens/new**
   (нужен вход в GitHub — подойдёт бесплатный аккаунт с доступом к репозиторию).
2. **Token name:** любое, например `Funscool admin`. **Expiration:** на своё усмотрение.
3. **Repository access** → **Only select repositories** → выбери
   **treasureclyde-sketch/sitesdemos**.
4. **Permissions** → **Repository permissions** → **Contents** → **Read and write**.
5. Нажми **Generate token** и **скопируй** его (показывается один раз).

---

## Часть 3. Редактировать (каждый день)

1. Открой **`https://treasureclyde-sketch.github.io/sitesdemos/admin/`** (сохрани в закладки).
2. Вставь токен из Части 2, нажми **Войти**. Токен запоминается в этом браузере —
   в следующий раз вход сразу.
3. Слева выбери раздел (**Воспитатели**, **Вопросы**), поменяй тексты/фото,
   нажми **Сохранить**. Через ~1 минуту правки появятся на сайте.

**Безопасность:** токен хранится только в браузере редактора и уходит напрямую в
GitHub API — больше никуда. Если браузер общий — сними галочку «Запомнить токен»
или нажимай «Выйти» после работы. Токен всегда можно отозвать на
https://github.com/settings/tokens.

---

## Заметки

- **Фото.** Пока в форме указывается путь к уже загруженному файлу
  (например, `assets/img/teachers/olympia.jpg`). Загрузку новых картинок прямо из
  панели можно добавить отдельно.
- **Заявки с формы.** Отправка заявок письмом раньше шла через функцию Netlify
  (`netlify/functions/lead.js`). На GitHub Pages серверных функций нет, поэтому этот
  способ здесь не работает — приём заявок нужно решить отдельно (например,
  сторонний сервис форм). Это не связано с админкой.

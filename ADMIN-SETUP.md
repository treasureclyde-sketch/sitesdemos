# Funscool — админка (Sveltia CMS + вход через GitHub): подробная инструкция

Через эту панель **администратор сада** меняет контент сайта сам, из браузера, простыми формами —
**без кода и без понимания GitHub**. Он заходит на `сайт/admin/`, входит одной кнопкой
«Sign in with GitHub», меняет фото/имя/текст и жмёт «Publish». Правка сохраняется в проект
(с полной историей — всегда можно откатить), и сайт сам пересобирается за ~1 минуту.

Стек: **Sveltia CMS** (сама панель, на нашем домене `сайт/admin/`) + **GitHub** (хранилище +
вход) + крошечный бесплатный **Cloudflare Worker** (только для безопасного входа).

**Кто что делает:**
- **Ты (владелец)** — один раз настраиваешь вход (Часть 1). ~15 минут.
- **Администратор сада** — потом просто редактирует (Часть 3). Ему нужен лишь бесплатный
  GitHub-аккаунт и один клик «войти».

**Что редактируется через панель сейчас:** блок **«Воспитатели»** (фото, имя, роль/теги,
описание — на трёх языках). Остальное (расписание, тексты, галерея) добавим тем же способом позже.

# Часть 1. Разовая настройка входа (делает владелец)

Вход через GitHub требует крошечного «посредника» (сам GitHub без него токен не отдаёт).
Мы поднимем бесплатный воркер на Cloudflare и свяжем его с GitHub. Порядок важен.

## Шаг 1.1 — Развернуть воркер на Cloudflare (бесплатно)
1. Заведи бесплатный аккаунт на **https://dash.cloudflare.com** (если ещё нет).
2. Открой репозиторий воркера: **https://github.com/sveltia/sveltia-cms-auth**
3. В его README нажми кнопку **«Deploy to Cloudflare Workers»** и пройди шаги
   (Cloudflare подключится к GitHub и сам развернёт воркер).
4. После деплоя запиши **адрес воркера** — он вида
   **`https://sveltia-cms-auth.ТВОЙ-ПОДДОМЕН.workers.dev`**. Он понадобится дальше.
   *(Пока переменные не заданы — это нормально, зададим в шаге 1.3.)*

## Шаг 1.2 — Создать GitHub OAuth App
1. Открой **https://github.com/settings/developers** → вкладка **OAuth Apps** →
   **New OAuth App**.
2. Заполни:
   - **Application name:** `Funscool CMS`
   - **Homepage URL:** адрес сайта (например, `https://regal-starburst-6fc954.netlify.app`)
   - **Authorization callback URL:** `https://sveltia-cms-auth.ТВОЙ-ПОДДОМЕН.workers.dev/callback`
     *(это адрес воркера из шага 1.1 с `/callback` на конце — впиши точно)*
3. **Register application**.
4. Скопируй **Client ID**. Нажми **Generate a new client secret** и скопируй **secret**
   (показывается один раз — сохрани сразу).

## Шаг 1.3 — Дать воркеру ключи от GitHub
1. Вернись в Cloudflare → свой воркер **sveltia-cms-auth** → **Settings → Variables**
   (переменные окружения).
2. Добавь три переменные (значения — в кавычки не заключать):
   - **`GITHUB_CLIENT_ID`** — Client ID из шага 1.2
   - **`GITHUB_CLIENT_SECRET`** — secret из шага 1.2 (лучше отметить «Encrypt»)
   - **`ALLOWED_DOMAINS`** — где открывается панель, через запятую. Впиши:
     `*.netlify.app,treasureclyde-sketch.github.io`
     *(позже добавишь сюда `funscool.rs`, когда подключишь домен)*
3. Сохрани и, если попросит, **Deploy** заново.

## Шаг 1.4 — Вписать адрес воркера в настройку панели
В файле **`funscool/admin/config.yml`** есть строка:
```
  base_url: https://REPLACE-WITH-YOUR-WORKER.workers.dev
```
Замени её на адрес своего воркера из шага 1.1, например:
```
  base_url: https://sveltia-cms-auth.tvoy-poddomen.workers.dev
```
> Не хочешь лезть в код — просто пришли мне адрес воркера, я впишу и запушу за минуту.

## Шаг 1.5 — Дать администратору доступ к репозиторию
1. Репозиторий на GitHub → **Settings → Collaborators → Add people**.
2. Впиши **GitHub-логин администратора** (одного человека, который будет вести сайт).
   Ему придёт приглашение — пусть примет.
   > Нет аккаунта? Пусть заведёт бесплатный на github.com (почта + пароль, 2 минуты).
   > Воспитателям отдельные логины **не нужны** — их карточки правит администратор.

# Часть 2. Проверить, что всё работает (2 минуты)

1. Открой **`https://<адрес-сайта>/admin/`** (например, на Netlify — `.../admin/`).
2. Нажми **«Sign in with GitHub»**, разреши доступ.
3. Слева выбери **Воспитатели → Список воспитателей**.
4. Поменяй что-нибудь мелкое (слово в описании) → **Save** → **Publish**.
5. Через ~1 минуту обнови сайт и убедись, что правка появилась. Верни как было.

Всё, можно передавать администратору ссылку `сайт/admin/`.

# Часть 3. Как редактировать — инструкция для администратора

### Как войти
1. Открой в браузере **`https://<адрес-сайта>/admin/`** (сохрани в закладки).
2. Нажми **«Sign in with GitHub»**, введи свой GitHub-логин и пароль, разреши доступ.
   Дальше с GitHub ты больше не сталкиваешься — только эта простая панель.

### Где что находится
- Слева — раздел **«Воспитатели» → «Список воспитателей»**: все карточки педагогов.

### Изменить фото / имя / роль / описание
1. Открой карточку в списке — увидишь простую форму:
   - **Фото** — кнопка загрузки (квадратное или вертикальное фото, лицо по центру).
   - **Акцентный цвет карточки** — выбор из списка.
   - **Имя** — три поля: Русский / Српски / English.
   - **Теги / роль** — маленькие плашки под именем (добавляй/удаляй).
   - **О себе / био** — три поля на трёх языках.
2. Если какого-то языка нет — оставь пустым, сайт подставит русский.
3. **Save** → **Publish**.

### Добавить / удалить / переставить воспитателя
- **Добавить:** внизу списка **«Add Воспитатель»**, заполни поля.
- **Удалить:** значок корзины у карточки.
- **Порядок:** перетащи карточку — как в списке, так и на сайте.

### Опубликовать (важно!)
Изменения появляются на сайте только после **Publish**:
1. **Save** (сохранить).
2. **Publish**.
3. Подожди **~1 минуту** и обнови сайт.

# Если что-то пошло не так

- **При входе ошибка / не пускает** — проверь, что домен, с которого открываешь `/admin/`,
  вписан в переменную `ALLOWED_DOMAINS` воркера (Часть 1, шаг 1.3), и что
  **Authorization callback URL** в GitHub OAuth App заканчивается на `/callback`.
- **«Not authorized» после входа** — администратор ещё не принял приглашение в репозиторий
  (Часть 1, шаг 1.5) или у него нет доступа к репозиторию.
- **Фото не загружается** — слишком большой файл; уменьши до ~1–2 МБ.
- **Ошиблись и хотите вернуть как было** — все версии хранятся в GitHub, любую правку
  можно откатить. Напиши мне — верну за минуту.
- **Какой адрес у панели** — это адрес сайта + `/admin/` в конце.

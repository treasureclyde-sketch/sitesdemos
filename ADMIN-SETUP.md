# Funscool — админка (Sveltia CMS, вход через Netlify): подробная инструкция

Через эту панель **администратор сада** меняет контент сайта сам, из браузера, простыми
формами — **без кода и без Cloudflare**. Он заходит на `сайт/admin/`, входит одной кнопкой
«Sign in with GitHub», меняет фото/имя/текст и жмёт «Publish». Правка сохраняется в проект
(с полной историей — всегда можно откатить), и сайт сам пересобирается за ~1 минуту.

Стек: **Sveltia CMS** (панель на нашем домене `сайт/admin/`) + **вход через встроенный OAuth
Netlify** (Cloudflare-воркер НЕ нужен, потому что сайт уже на Netlify).

**Кто что делает:**
- **Ты (владелец)** — один раз настраиваешь вход (Часть 1). ~10 минут, всё мышкой.
- **Администратор сада** — потом просто редактирует (Часть 3). Нужен бесплатный GitHub-аккаунт
  и один клик «войти».

**Что редактируется сейчас:** блок **«Воспитатели»** (фото, имя, роль/теги, описание — на трёх
языках). Остальное добавим тем же способом позже.

# Часть 1. Разовая настройка входа (делает владелец, ~10 минут)

Вход через GitHub требует «посредника», который обменивает логин на доступ. Раньше я предлагал
поднимать его на Cloudflare — но раз сайт на **Netlify**, этот посредник у тебя **уже есть**,
его нужно только включить. Никакого Cloudflare.

## Шаг 1.1 — Убедись, что сайт открыт на Netlify
1. Зайди на **https://app.netlify.com**, открой свой сайт Funscool.
2. Запиши его адрес — вида **`https://имя-сайта.netlify.app`**. Именно с него будет работать
   вход и открываться панель `/admin/`.
   > Панель работает с **адреса Netlify**. (На GitHub Pages вход не заработает — там нет Netlify.)

## Шаг 1.2 — Создать GitHub OAuth App (ключ для входа)
1. Открой **https://github.com/settings/developers** → вкладка **OAuth Apps** →
   **New OAuth App**.
2. Заполни:
   - **Application name:** `Funscool CMS`
   - **Homepage URL:** адрес сайта из шага 1.1 (например, `https://имя-сайта.netlify.app`)
   - **Authorization callback URL:** `https://api.netlify.com/auth/done`
     *(впиши ровно так — это адрес входа Netlify)*
3. **Register application**.
4. Скопируй **Client ID**. Нажми **Generate a new client secret** и скопируй **secret**
   (показывается один раз — сохрани сразу).

## Шаг 1.3 — Включить вход GitHub в Netlify
1. В Netlify открой свой сайт → **Site configuration** → раздел **Access & security**
   → блок **OAuth** (в некоторых версиях путь: **Access control → OAuth →
   Authentication providers**).
2. Нажми **Install provider** и выбери **GitHub**.
3. Вставь **Client ID** и **Client Secret** из шага 1.2 → сохрани (**Install / Save**).
   *(Это связывает вход на сайте с твоим GitHub — панель сможет сохранять правки.)*

## Шаг 1.4 — Дать администратору доступ к репозиторию
1. Репозиторий на GitHub → **Settings → Collaborators → Add people**.
2. Впиши **GitHub-логин администратора** (одного человека, который будет вести сайт) — ему
   придёт приглашение, пусть примет.
   > Нет аккаунта? Пусть заведёт бесплатный на github.com (почта + пароль, 2 минуты).
   > Воспитателям отдельные логины **не нужны** — их карточки правит администратор.

Готово. Больше ничего настраивать не надо.

# Часть 2. Проверить, что всё работает (2 минуты)

1. Открой **`https://имя-сайта.netlify.app/admin/`**
2. Нажми **«Sign in with GitHub»**, разреши доступ.
3. Слева выбери **Воспитатели → Список воспитателей**.
4. Поменяй что-нибудь мелкое (слово в описании) → **Save** → **Publish**.
5. Через ~1 минуту обнови сайт и убедись, что правка появилась. Верни как было.

Всё — можно передавать администратору ссылку `сайт/admin/`.

# Часть 3. Как редактировать — инструкция для администратора

### Как войти
1. Открой в браузере **`https://имя-сайта.netlify.app/admin/`** (сохрани в закладки).
2. Нажми **«Sign in with GitHub»**, введи свой GitHub-логин и пароль, разреши доступ.
   Дальше с GitHub ты больше не сталкиваешься — только эта простая панель.

### Где что находится
- Слева — раздел **«Воспитатели» → «Список воспитателей»**: все карточки педагогов.

### Изменить фото / имя / роль / описание
1. Открой карточку в списке — увидишь простую форму:
   - **Фото** — кнопка загрузки (квадратное или вертикальное фото, лицо по центру).
   - **Акцентный цвет карточки** — выбор из списка.
   - **Имя** — три поля: Русский / Српски / English.
   - **Теги / роль** — маленькие плашки под именем (добавляй/удаляй).
   - **О себе / био** — три поля на трёх языках.
2. Если какого-то языка нет — оставь пустым, сайт подставит русский.
3. **Save** → **Publish**.

### Добавить / удалить / переставить воспитателя
- **Добавить:** внизу списка **«Add»** (Добавить), заполни поля.
- **Удалить:** значок корзины у карточки.
- **Порядок:** перетащи карточку — как в списке, так и на сайте.

### Опубликовать (важно!)
Изменения появляются на сайте только после **Publish**:
1. **Save** (сохранить).
2. **Publish**.
3. Подожди **~1 минуту** и обнови сайт.

# Если что-то пошло не так

- **При входе окно закрывается / «unauthorized»** — проверь: панель открыта с адреса
  **`*.netlify.app`** (а не GitHub Pages); в GitHub OAuth App **Authorization callback URL**
  ровно `https://api.netlify.com/auth/done`; в Netlify включён провайдер **GitHub**
  (шаг 1.3) с правильными Client ID / Secret.
- **«Not authorized» уже после входа** — администратор не принял приглашение в репозиторий
  (шаг 1.4) или у него нет доступа к репозиторию.
- **Не могу найти OAuth в Netlify** — ищи в настройках сайта раздел со словом **OAuth**
  (Access & security / Access control). Если совсем нет — напиши мне, подскажу по твоей версии.
- **Фото не загружается** — слишком большой файл; уменьши до ~1–2 МБ.
- **Ошиблись и хотите вернуть как было** — все версии хранятся в GitHub, любую правку можно
  откатить. Напиши мне — верну за минуту.

Вход по токену GitHub — без Netlify и сторонних сервисов.

Как получить токен (один раз, ~1 минута):
  1. Открой создание fine-grained токена (нужен вход в GitHub).
  2. Repository access → «Only select repositories» → выбери treasureclyde-sketch/sitesdemos.
  3. Permissions → Contents → Read and write.
  4. Нажми Generate token, скопируй и вставь ниже.

Токен хранится только в этом браузере и отправляется напрямую в GitHub. Никому больше не передаётся.

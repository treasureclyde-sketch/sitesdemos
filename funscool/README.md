# Funscool — бутик-детский сад · Белград

Мультиязычный (**RU / SR / EN**) сайт частного детского сада Funscool
(Дорчол, Белград) — построен по дизайн-макетам из ТЗ.

## Что внутри
- `index.html` — вся разметка (русский текст встроен для SEO/no-JS)
- `assets/css/style.css` — дизайн-система и стили, без фреймворков
- `assets/js/main.js` — интерактив + i18n (словари SR/EN, RU берётся из разметки)
- `assets/img/` — фото интерьеров, педагогов, детей, площадки
- `assets/img/favicon.svg` — иконка (смайл)

## Секции
Hero → 4 преимущества → рейтинг/адрес → «Среда развития» → **Программы по
возрастам** (Беби-Фан 1,5–2,5 · Энерджи-Фан · Дискавери-Фан · Креатив-Фан ·
Прескул 6–7) → площадка → «Дом с историей» → «360° развитие» (анимированные
радиальные часы дня) → «Радость каждый день» → фотогалерея «Счастливые
моменты» → педагоги → FAQ → форма-заявка → футер.

## Мультиязычность
Переключатель RU/SR/EN в шапке. Русский — базовый (встроен в HTML),
сербский и английский — словари в `main.js`. Выбор запоминается (localStorage),
телефон меняется по языку (RU/EN +7, SR +381).

## Дизайн
- Тёплая крем-палитра, элегантный сериф **Lora** + дружелюбный **Nunito**
- Скруглённые карточки, пастельные акценты по возрастным группам, ручные дудлы
- Полная адаптивность, `prefers-reduced-motion`, аудит impeccable (0 находок)

## Запуск
```bash
cd funscool && python3 -m http.server 8099
# http://localhost:8099
```

# Письма с заявок — настройка (Google Apps Script)

Сайт живёт на **GitHub Pages** (статика — сам письма слать не умеет). Отправку
берёт на себя маленький **Google Apps Script**: форма на сайте передаёт ему
заявку, а он собирает фирменное письмо-табличку и шлёт его **с твоего Gmail** на
нужные почты. Бесплатно, без Netlify, без сборок и без кредитов.

Скрипт лежит в репозитории: **`apps-script/Code.gs`**.

---

## Шаг 1. Создать скрипт

1. Открой https://script.google.com → **New project**.
2. Удали пример в редакторе и вставь **весь** файл `apps-script/Code.gs`.
3. Вверху `LEAD_TO` — кому приходят заявки. Уже стоит:
   ```
   Kseniyashipareva@gmail.com, Raziusha0809@gmail.com, Welcome@funscool.rs
   ```
   (можно менять / добавлять через запятую).
4. Аккаунт Google, в котором создаёшь скрипт, = **отправитель** письма
   (в поле «От кого» будет он). Хочешь, чтобы слалось с конкретной почты —
   создавай проект под ней.

## Шаг 2. Опубликовать как веб-приложение

1. Кнопка **Deploy → New deployment**.
2. Шестерёнка **Select type → Web app**.
3. Настройки:
   - **Execute as:** `Me` (с твоего аккаунта уходит письмо)
   - **Who has access:** `Anyone`
4. **Deploy** → Google попросит **разрешить доступ** (Authorize access) →
   выбери свой аккаунт → «Advanced» → «Go to project (unsafe)» → Allow.
   (Это нормально: доступ к Gmail нужен, чтобы скрипт мог отправлять письмо.)
5. Скопируй **Web app URL** — он заканчивается на **`/exec`**. Вот его и пришли
   мне, я подключу форму сайта.

## Шаг 3. Проверка (после того как я подключу форму)

1. Открой сайт → форма «Записаться на экскурсию» → заполни и отправь.
2. Придёт письмо-табличка на почты из `LEAD_TO` — готово. 🎉
   («Ответить» отвечает прямо родителю на его e-mail.)
3. Если письма нет — глянь в Apps Script → **Executions** (слева часики):
   там видно каждый вызов и ошибку, если что-то не так.

---

## Если надо поменять получателей позже

Просто отредактируй `LEAD_TO` в скрипте и снова **Deploy → Manage deployments →
Edit → Version: New version → Deploy** (URL останется тот же).

## Как это устроено в коде сайта

- `apps-script/Code.gs` — принимает JSON заявки, собирает HTML-письмо и шлёт
  через `GmailApp` с твоего аккаунта; `replyTo` = e-mail родителя.
- Адрес скрипта (`/exec`) задан в вёрстке в двух местах — их подставляю я:
  - `funscool/assets/js/main.js` — константа `LEAD_ENDPOINT`;
  - `funscool/index.html` и `funscool/group.html` — атрибут `action` у формы.
- Запасной канал: если скрипт недоступен, форма показывает кнопку WhatsApp с
  уже заполненным текстом заявки — заявка не теряется.

> Netlify для писем больше не нужен — этот путь его полностью заменяет.

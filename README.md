# Free Fly — редизайн сайта аэротрубы

Современный редизайн лендинга аэротрубы **Free Fly** (Екатеринбург) —
[фрифлай.рф](https://xn--80apegxxc.xn--p1ai). Одностраничный сайт с
кинематографичной тёмной темой, эффектом «стеклянной трубы» и полной
адаптивностью.

## Что внутри

- `index.html` — вся разметка лендинга
- `assets/css/style.css` — дизайн-система и стили (без фреймворков)
- `assets/js/main.js` — интерактив на чистом JS (без зависимостей)
- `assets/img/photos/` — реальные фотографии полётов с сайта Free Fly
- `assets/img/brand/logo.png` — логотип

## Секции

1. **Hero** — полноэкранный экран с фото полёта, стеклянными полосами,
   свечениями и живыми частицами ветра
2. Бегущая строка
3. **Что такое аэротруба** — описание + фото + факты
4. **4 преимущества** — Безопасно / Удобно / Выгодно / Доступно
5. **Характеристики** — 350 кВт · 250 км/ч · 15 км · 120 кг (анимированные счётчики)
6. **Тарифы и акции** — 6 предложений (буднего дня −50%, детский, ДР +5 мин,
   корпоратив, школа Fly Kids, акция с отелем)
7. **Кому подходит** — бенто-сетка форматов (подарок, ДР, корпоратив,
   свидание, Fly Kids, спорт)
8. **Как проходит полёт** — 4 шага
9. **Галерея**, соцдоказательство, **FAQ**
10. **Заявка** — контакты + форма с маской телефона
11. **Футер** — услуги, города сети, реквизиты, 0+

## Дизайн-система

- **Тема:** immersive / spatial glass, тёмный кинематографичный фон
- **Цвета:** тёмно-синий (navy) + электрик-синий `#2E7DFF` + энергичный
  янтарь `#FFB020`
- **Шрифты:** Unbounded (display) + Manrope (текст) — полная кириллица
- **Анимации:** scroll-reveal, счётчики, параллакс-свечения, hover-эффекты;
  учитывается `prefers-reduced-motion`
- Дизайн-направление подобрано через скилл **ui-ux-pro-max** и референсы
  из **21st.dev**

## Запуск

Статический сайт — открывается без сборки:

```bash
python3 -m http.server 8099
# http://localhost:8099
```
